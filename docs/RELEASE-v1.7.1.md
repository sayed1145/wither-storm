## 下载与安装

`Wither-Storm-v1.7.1.jar` 是直接导入游戏的文件。完整包包含源码和资源；不要把 GitHub 自动生成的源码 ZIP 当作模组安装包。

版本号仍为 **1.7.1**。已安装旧署名 v1.7.1 的用户需要重新导入本发布 JAR，才能更新作者显示；这次不改变存档版本或玩法行为。
